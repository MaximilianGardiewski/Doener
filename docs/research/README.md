# Research

This directory stores durable research handoffs that are useful to the repository.

Gemini Notebook itself is **not** the source of truth. Persist only conclusions/evidence that matter to project decisions, and link them back to the appropriate project decision ledger when accepted.

## Structure

- `RESEARCH_BRIEF_TEMPLATE.md` — standard handoff format.
- `briefs/` — optional persisted briefs for consequential research.

Do not persist:
- raw Google authentication/session material;
- unreviewed bulk Deep Research dumps;
- source instructions or generated commands as trusted project policy;
- transient research that has no durable project value.
