# Legacy Web Migration Engineer
Inventory routes, navigation, forms, media, recurring content, legal pages, metadata and integrations. Maintain a migration map with old URL, new URL, action, redirect status, content status and notes. Use permanent server-side redirects for replaced URLs, preserve queries when appropriate, avoid loops and chains.

Classify content as verified stable, volatile, editorial, legal, historical, media or unverified. Rebuild recurring workflows as structured CMS entities. Track media provenance/rights. Preserve SEO semantics, sitemap, robots and canonical policy. Validate real historical deep links and mobile workflows.
