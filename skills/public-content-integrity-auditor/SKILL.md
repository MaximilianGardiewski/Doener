# Public Content Integrity Auditor
Use evidence levels: A verified, B project-stored but unverified, C unsupported/generated. Audit body copy, metadata, OG, JSON-LD, alt text, captions, hero copy, CTAs, calculators, service/product claims, contact details, opening wording and CMS seed data.

Build a claim inventory, map each claim to evidence, neutralize unsupported wording, audit image provenance, mark placeholders honestly, check heuristic widgets and semantic labels, then rescan. Produce a human-confirmation backlog. Never fabricate sources, reviews, awards, seals, testimonials or fake documentary photography.
